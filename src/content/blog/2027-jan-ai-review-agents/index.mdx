## Working thesis (to confirm)

In six weeks our pull requests had three AI review agents, and two were removed. One remains. It runs only on request, and a second agent with fresh context checks its findings before they are posted.

The title says "three review agents" and not "I added three", because the vendor review action was in the repository before the custom agent arrived.

## Numbers available

**The custom agent, first live sample (12 September).** One review of its own pull request:

| Measure | Value |
| --- | ---: |
| Analysis duration | 17 min 12 s |
| Publisher duration | 54 s |
| Model turns | 72 |
| Total tokens | 3,665,597 |
| Estimated model cost | USD 4.3333 |
| Result | Three findings, none a blocker |

**The third reviewer, pilot (1 October).** One run against a fixed pull request head:

| Measure | Value |
| --- | ---: |
| Duration | 26 min 50 s |
| Requests over the 300-second limit | 3 |
| File-tool calls | 79, all passed |
| Reported input tokens | 1,688,080 (includes repeated request input) |
| Reported output tokens | 134,780 |
| Result | Failed, 0 of 4 selected files complete |

A successful full run was not confirmed, and the pilot does not support a replacement of the custom agent.

These are two single runs on two different pull requests. The post must not compare the tools on them.

## Section plan

1. **The result first.** Three reviewers, two removed, one left on request. State that the comparison rests on one pilot for each tool.
2. **The first design and its safety model.** Analysis from trusted base code, no execution of pull request code, read-only access for analysis, a separate publisher, a check of the pull request head before each write.
3. **The cost and speed changes in the first week.** Three reviewers at most, one batch for verification, a smaller model, then a different provider. Needs question 2.
4. **The third reviewer.** What the pilot measured and what it did not show.
5. **The removal.** Needs question 1.
6. **What remains.** The label trigger and the validator.
7. **What I did not measure.** Needs question 3.

## Questions for the author

2. What did one review cost, for each reviewer? There is one estimate, USD 4.3333 for the first sample of the custom agent, and there are token counts for one failed pilot of the third reviewer.
3. How many findings were correct? Is there a count for any reviewer?

## Limits that the post must state

- The post compares products on thin data: one run for each of two tools. It reports what was measured and makes no general claim about a tool.
- The validator rules are instructions in a prompt. Nothing in the pipeline enforces them.
- There is no count of correct findings.
